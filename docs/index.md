# Contabo Provider (hayone1 distribution)

This provider is an unofficial distribution of the Contabo Terraform provider. This distribution is not made by Contabo GmbH, and it is not connected to Contabo GmbH.

The distribution starts from the [official provider](https://github.com/contabo/terraform-provider-contabo) and adds patches that Contabo has not merged yet. The file [PATCHES.md](https://github.com/hayone1/terraform-provider-contabo/blob/main/PATCHES.md) lists every patch. When Contabo merges a patch into the official provider, the distribution stops carrying its own copy of that patch.

The provider manages the products that [Contabo](https://contabo.com) offers. These products include Cloud VPS and VDS instances, firewalls, private networks, virtual IP addresses, DNS zones and records, reverse DNS records, object storage, custom images, snapshots, secrets, tags, roles and users. The provider needs the API credentials from the [Customer Control Panel](https://my.contabo.com/api/details) of your Contabo account.

~> **Warning about costs:** When Terraform creates a `contabo_instance` resource or a `contabo_object_storage` resource, Contabo orders the product and starts to bill you for the product. When Terraform destroys one of these resources, Contabo cancels the product at the end of the contract period.

## Example Usage

```terraform
terraform {
  required_providers {
    contabo = {
      source  = "hayone1/contabo"
      version = ">= 0.2.0"
    }
  }
}

# Configure your Contabo API credentials in the provider block or with the
# CNTB_OAUTH2_CLIENT_ID, CNTB_OAUTH2_CLIENT_SECRET, CNTB_OAUTH2_USER and
# CNTB_OAUTH2_PASS environment variables.
provider "contabo" {
  oauth2_client_id     = "[your client id]"
  oauth2_client_secret = "[your client secret]"
  oauth2_user          = "[your username]"
  oauth2_pass          = "[your password]"
}

# Create a default contabo VPS instance
resource "contabo_instance" "default_instance" {}

# Output our newly created instances
output "default_instance_output" {
  description = "Our first default instance"
  value       = contabo_instance.default_instance
}
```

## Moving from `contabo/contabo`

The resources of this distribution use the same schema as the resources of the official provider. Because the schemas match, you can keep your existing Terraform state. Follow these steps:

1. In the `required_providers` block, change `source = "contabo/contabo"` to `source = "hayone1/contabo"`.
2. Run `terraform init -upgrade`.
3. Run `terraform state replace-provider registry.terraform.io/contabo/contabo registry.terraform.io/hayone1/contabo`. If you use OpenTofu, write `registry.opentofu.org` instead of `registry.terraform.io` in both addresses.
4. Run `terraform plan` and read the plan carefully before you apply the plan. The [changelog](https://github.com/hayone1/terraform-provider-contabo/blob/main/CHANGELOG.md) explains which behavior changed.

## Schema

### Optional

- `api` (String) The api endpoint is https://api.contabo.com.
- `oauth2_client_id` (String) Your oauth2 client id can be found in the [Customer Control Panel](https://new.contabo.com/account/security) under the menu item account secret.
- `oauth2_client_secret` (String) Your oauth2 client secret can be found in the [Customer Control Panel](https://new.contabo.com/account/security) under the menu item account secret.
- `oauth2_pass` (String) API Password (this is a new password which you'll set or change in the [Customer Control Panel](https://new.contabo.com/account/security) under the menu item account secret.)
- `oauth2_token_url` (String) The oauth2 token url is https://auth.contabo.com/auth/realms/contabo/protocol/openid-connect/token.
- `oauth2_user` (String) API User (your email address to login to the [Customer Control Panel](https://new.contabo.com/account/security) under the menu item account secret.
