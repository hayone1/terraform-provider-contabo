# Contabo Provider (hayone1 distribution)

Unofficial distribution of the Contabo Terraform provider. Not made by or connected to Contabo GmbH.

It is the [upstream provider](https://github.com/contabo/terraform-provider-contabo) plus patches that are not merged upstream yet, listed in [PATCHES.md](https://github.com/hayone1/terraform-provider-contabo/blob/main/PATCHES.md). When upstream merges a patch, this distribution drops its own copy.

The provider manages resources offered by [Contabo](https://contabo.com): Cloud VPS and VDS instances, firewalls, private networks, virtual IPs, DNS zones and records, reverse DNS, object storage, custom images, snapshots, secrets, tags, roles and users. It needs the API credentials from the [Customer Control Panel](https://my.contabo.com/api/details).

~> **Costs:** creating a `contabo_instance` or `contabo_object_storage` orders a product and starts billing. Destroying it cancels the product at the end of its contract period.

## Example Usage

```terraform
terraform {
  required_providers {
    contabo = {
      source  = "hayone1/contabo"
      version = ">= 0.2.0"
    }
  }
}

# Configure your Contabo API credentials in the provider block or with the
# CNTB_OAUTH2_CLIENT_ID, CNTB_OAUTH2_CLIENT_SECRET, CNTB_OAUTH2_USER and
# CNTB_OAUTH2_PASS environment variables.
provider "contabo" {
  oauth2_client_id     = "[your client id]"
  oauth2_client_secret = "[your client secret]"
  oauth2_user          = "[your username]"
  oauth2_pass          = "[your password]"
}

# Create a default contabo VPS instance
resource "contabo_instance" "default_instance" {}

# Output our newly created instances
output "default_instance_output" {
  description = "Our first default instance"
  value       = contabo_instance.default_instance
}
```

## Migrating from `contabo/contabo`

Resource schemas are compatible with the official provider, so existing state can be moved:

1. Change `source = "contabo/contabo"` to `source = "hayone1/contabo"` in `required_providers`.
2. Run `terraform init -upgrade`.
3. Run `terraform state replace-provider registry.terraform.io/contabo/contabo registry.terraform.io/hayone1/contabo`. With OpenTofu, use `registry.opentofu.org` in both addresses.
4. Run `terraform plan` and check the changes. Behavior changes are listed in the [changelog](https://github.com/hayone1/terraform-provider-contabo/blob/main/CHANGELOG.md).
